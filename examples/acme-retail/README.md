# Example client: Acme Retail (fictional)

A complete client deployment for a fictional retailer, laid out exactly as it would sit in a client's
own repo. Use it as a reference while filling in your own, or to try the engine end to end.

| Path | What it is |
|---|---|
| `client/profile.yaml` | the profile: every field annotated |
| `client/benchmark-cases.json` | benchmark prompts written around Acme's tickets and tables |
| `services/config/*.yaml` | generated by `render` from the profile |
| `docs/ai/client/client.md`, `repo-registry.md`, `repo-map.md` | generated by `render` |
| `docs/ai/client/*-architecture.md`, `fabric-conventions.md`, `lineage-*` | domain docs written by people, the level of detail worth aiming for |

The engine's test suite re-renders this profile and checks the result matches the generated files
here byte for byte, so the example always reflects what `render` really produces.

To try it: `cd services && python -m app.setup init --from ../examples/acme-retail/client/profile.yaml`,
then `render` (see [`../../SETUP.md`](../../SETUP.md)).
